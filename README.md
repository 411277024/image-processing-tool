# 影像處理工具

大三課堂作業，以 Python 獨立完成的影像處理桌面工具。左右並排顯示原圖與處理結果，可即時比較、重置與儲存。

## 功能

- 灰階轉換
- 黑白二值化：閾值可手動調整，或由灰階平均值自動估計
- 色彩量化：以 Median Cut 縮減顏色數量
- 銳化處理
- 局部美顏：框選區域後套用中值濾波，強度可調
- 自由畫筆：顏色與粗細可調

## 技術

Python、Tkinter、Pillow、NumPy

## 執行方式

```bash
pip install pillow numpy
python image_editor.py
```

## 實作重點與限制

- 局部操作需要把畫面座標換算回原圖座標，處理縮放與偏移
- 多數功能使用 Pillow 內建函式；自動閾值以灰階平均值估計，並非 Otsu 演算法
